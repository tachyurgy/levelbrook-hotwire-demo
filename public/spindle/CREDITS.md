# Spindle audio — provenance

The Spindle player demonstrates two playback paths:

1. **Live-synthesized albums** (Night Shipping, Broadcast Drift) — no audio files
   exist. Every note is generated in real time in the browser by the Web Audio
   API (`app/javascript/controllers/synth_controller.js`).

2. **File-backed albums** — the MP3s in this directory. All tracks are released
   under **CC0 1.0 (public domain dedication)** — no attribution required,
   free for commercial use. Sources recorded here purely as good practice:
